개인정보처리방침 (Privacy Policy)

최종 수정일: 2026년 11월 22일  |  적용 대상: 네줍기 (엔페이 포인트 자동 줍기) Chrome 확장 프로그램

1. 개요 (Overview)

본 개인정보처리방침은 네줍기 (엔페이 포인트 자동 줍기) 확장 프로그램이 사용자의 정보를 어떻게 다루는지 투명하게 설명하기 위해 작성되었습니다. 본 확장 프로그램은 사용자의 프라이버시를 최우선으로 존중하며, 계정 비밀번호·쿠키·결제 정보 등 어떠한 개인정보도 수집, 전송, 보관하지 않고 미션 목록 및 서비스 규칙 동기화를 위한 최소한의 비식별 API 통신만 수행합니다.

2. 수집 및 처리하는 정보 (Data Handled)

  • 계정 자격 증명(ID/Password) 비수집: 사용자의 아이디, 비밀번호, 결제 정보 등 민감한 개인 식별 정보를 입력받거나 저장하지 않습니다. 사용자가 브라우저에서 기존에 로그인해 둔 정상적인 네이버 세션을 브라우저 내부에서만 활용합니다.
  • 네이버 로그인 세션 확인 (Cookies): 브라우저에 저장된 네이버 로그인 쿠키(NID_AUT, NID_SES)의 유효 여부만을 브라우저 로컬 상에서 일시 확인하여 로그인 상태를 안내하며, 쿠키 값을 외부로 유출하거나 기록하지 않습니다.
  • 사용자 설정 및 통계 (Storage): 사용자 지정 동작 딜레이, 1원 미션 제외 옵션, 매일 실행 예약 시각, 당일 적립 완료 통계 등은 사용자의 로컬 브라우저 내부 스토리지(chrome.storage.local)에만 격리 보관됩니다.
  • 비식별 서비스 운영 통신: 최신 공개 미션 목록 및 실행 설정 동기화, 만료된 공개 미션 제외 처리, 서비스 개선용 비식별 익명 사용 통계 등 최소한의 비식별 데이터만을 처리합니다.

3. Chrome 확장 프로그램 권한 사용 목적 (Permissions Justification)

  • sidePanel: 사용자 웹 브라우징을 방해하지 않고 우측 패널에서 실시간 적립 모니터링 및 컨트롤 UI 제공
  • storage: 사용자 환경 설정값 및 적립 통계 브라우저 로컬 저장
  • tabs & scripting: 네이버페이 혜택 미션 페이지 열기, 페이지 로딩 감지, 포인트 받기 버튼 클릭 및 적립 완료 후 탭 자동 종료
  • offscreen: Manifest V3 규격에 따라 미션 완료 알림음(HTML5 Audio)을 백그라운드에서 재생
  • alarms: 사용자가 지정한 매일 예약 시각 및 예정 쇼핑라이브(+10분) 1회성 자동 실행 스케줄링
  • cookies: 네이버 로그인 세션 유지 여부 판정
  • host_permissions (point.pay.naver.com, *.pay.naver.com, nid.naver.com, *.naver.com, *.adison.co, nsl.pincrux.com): 네이버페이 혜택 목록·미션 페이지, 제휴 광고(adison/pincrux)·쇼핑라이브 도달 감지 및 네이버 로그인 상태 확인

4. 제3자 제공 및 외부 전송 (Third-Party Sharing & Data Transfers)

본 확장 프로그램은 개인식별정보(PII), 계정 정보, 쿠키, 브라우징 기록을 외부로 전송하거나 제3자에게 판매·공유하지 않습니다. 최신 공개 미션 정보 및 설정 동기화와 서비스 개선용 비식별 익명 사용 통계 처리에 필요한 최소한의 범위 내에서만 서버 통신을 수행합니다.

5. 영문 개인정보처리방침 (English Summary for Chrome Web Store Review)

English Statement:
glean-bot ("the Extension") does NOT collect, store, transmit, or sell any personally identifiable information (PII), account credentials, cookies, financial details, or browsing history. Mission execution and scheduling occur within the user's local browser using chrome.storage.local and active local browser sessions. Network requests are strictly limited to syncing public mission lists and configuration, filtering expired public missions, and processing non-identifying anonymous usage metrics for service reliability.
