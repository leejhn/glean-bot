네줍기 (네이버페이 포인트 줍줍하기)

네이버페이 혜택 미션(15원 · 10원 · 5원 · 2원 · 1원 · 쇼핑라이브)을 일일이 클릭할 필요 없이,
브라우저의 고정 사이드 패널(Side Panel)에서 안전하게 자동 수행하고 적립 내역까지 검증합니다.

✨ 핵심 기능 (Key Features)

🖥️

상시 고정 사이드 패널 & 실제 적립 검증

화면 어디를 클릭해도 닫히지 않는 사이드 패널에서 실시간 진행률, 분할 게이지, 라이트/블랙 테마를 지원하며 작업 완료 후 네이버페이 포인트 내역을 자동 대조해 실제 적립 금액을 검증합니다.

🔍

지능형 미션 수집 & 실시간 무효 링크 필터링

15원 · 10원 · 5원 · 2원 · 1원 미션과 쇼핑/보험 추가 링크를 통합 수집하고, 이미 참여한 미션과 커뮤니티 히든 미션·만료된 링크를 실시간으로 걸러냅니다.

🛡️

쇼핑라이브 무음 적립 & 사람다운 안전 체류

제휴 광고망(adcr, pincrux 등) 리다이렉트 감지, 불규칙 랜덤 딜레이(2~4초), 체류형 페이지 3~5초+ 안전 체류 및 쇼핑라이브 자동 음소거 적립을 지원합니다.

⏰

매일 예약 실행 & 예정 라이브 자동 예약

원하는 시각(예: 09:00)을 설정하면 브라우저 실행 중 매일 자동 가동되며, 예정된 쇼핑라이브 방송을 감지해 시작 10분 후 1회성 라이브 적립을 자동 예약할 수 있습니다.

🚀 간편 사용 방법 (Quick Start)

1
사이드 패널 열기

Chrome 우측 상단 툴바에서 네줍기 (네이버페이 포인트 줍줍하기) 아이콘을 클릭하여 사이드 패널을 엽니다. (핀 고정 권장)

2
로그인 및 옵션 설정

평소 사용하는 네이버 계정으로 로그인한 후, 1원 미션 제외, 쇼핑/보험 추가 링크 포함, 매일 예약 시각, 예정 라이브 자동 예약을 자유롭게 설정합니다.

3
[▶ 자동 적립 시작] 클릭

버튼 클릭 즉시 봇이 혜택 페이지를 스크롤 분석하여 일반 미션(15원~1원)과 쇼핑라이브, 추가 혜택 미션을 안전하게 순차 수행합니다.

🛡️ 개인정보 보호 & Zero-Trust 보안

개인정보 비수집 & 최소 서버 통신: 본 확장 프로그램은 계정 비밀번호, 쿠키, 결제 정보, 개인 토큰 URL 등 어떠한 개인정보도 수집·전송하지 않고 사용자의 브라우저 로컬 세션과 chrome.storage.local만으로 미션을 수행합니다. 다만 최신 공개 미션 목록 및 실행 규칙 동기화, 종료된 공개 링크 필터링, 비식별 익명 사용 통계를 위해 공식 Cloudflare Worker API 서버(glean-bot.leejhn.workers.dev)와 최소한의 통신만 수행합니다.

개인정보 비수집 & 로컬 세션 실행: 본 확장 프로그램은 계정 비밀번호, 쿠키, 결제 정보 등 개인정보를 일절 수집·전송하지 않으며 사용자의 브라우저 로컬 세션과 chrome.storage.local을 기반으로 동작합니다. 최신 공개 미션 정보 동기화 및 서비스 안정성 유지를 위해 최소한의 비식별 통신만 사용합니다.
