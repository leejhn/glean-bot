엔페이 포인트 자동 줍기(glean-bot)

네이버페이 혜택 미션(15원 · 10원 · 2원 · 1원)을 일일이 클릭할 필요 없이,
브라우저 우측 상시 고정 사이드 패널(Side Panel)에서 안전하게 자동 수행합니다.

🧩 Chrome 웹스토어에서 무료 설치하기

▲ 좌측 네이버페이 혜택 화면과 우측 상시 고정 glean-bot 사이드 패널의 실시간 모니터링 동작 화면

✨ 핵심 기능 (Key Features)

🖥️

상시 고정 사이드 패널 관제

기존 팝업창과 달리 화면 어디를 클릭해도 닫히지 않고 우측에 고정되어 실시간 진행률(Progress Bar), 금액별 적립 현황, 상세 터미널 로그를 상시 모니터링할 수 있습니다.

🔍

지능형 미션 소스 분석 & 필터링

15원, 10원, 2원, 1원 미션을 카테고리별로 자동 분류하며 이미 완료된 미션(type_has_points)과 Alert 충돌을 유발하는 불필요 링크를 사전에 정밀하게 걸러냅니다.

🛡️

사람다운 안전 체류 & 랜덤 딜레이

미션 유형별 정밀 타이머와 제휴 광고망(adcr, pincrux 등) 리다이렉트를 지능형으로 감지합니다. 사람다운 불규칙 랜덤 딜레이(2~4초)와 최종 도달 3초+ 안전 체류를 보장합니다.

⏰

매일 정해진 시각 자동 예약 실행

원하는 시각(예: 23:00)을 설정해 두면 브라우저가 실행 중일 때 사람 손을 댈 필요 없이 매일 정해진 시간에 스스로 가동되어 무인 적립을 완료하고 맑은 화음 비프음을 재생합니다.

🚀 간편 사용 방법 (Quick Start)

1
사이드 패널 열기

Chrome 우측 상단 툴바에서 glean-bot 아이콘을 클릭하여 사이드 패널을 엽니다. (핀 고정 권장)

2
로그인 및 옵션 설정

평소 사용하는 네이버 계정으로 로그인한 후, 1원 미션 제외 여부나 매일 자동 예약 시간을 자유롭게 설정합니다.

3
[▶ 자동 적립 시작] 클릭

버튼 클릭 즉시 봇이 혜택 페이지를 스크롤 분석하여 15원부터 1원까지 순차적으로 탭을 열고 닫으며 안전하게 적립을 수행합니다.

🛡️ 개인정보 보호 & Zero-Trust 보안

100% 로컬 클라이언트 동작: 본 확장 프로그램은 개발자 서버나 외부 제3자 서버와의 네트워크 통신이 원천적으로 차단되어 있습니다. 계정 비밀번호나 개인정보를 수집하지 않으며 오직 사용자의 브라우저 로컬 세션과 chrome.storage.local만을 활용합니다.
