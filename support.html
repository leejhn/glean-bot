자주 묻는 질문 (FAQ)

네줍기 (엔페이 포인트 자동 줍기) 확장 프로그램 사용 시 자주 묻는 질문과 해결 방법입니다.

자주 묻는 질문 (FAQ)

Q0실제 적립되는 금액과 차이가 발생할 수 있나요?

A. 네줍기는 작업 종료 후 네이버페이 포인트 내역을 자동 대조하여 실제 적립 포인트를 집계해 드립니다. 다만 포인트 반영 지연, 제휴사 광고 예산 조기 소진, 과거 참여 여부 등에 따라 기대 미션 수와 실제 적립 금액에 차이가 발생할 수 있으므로, 최종 내역은 네이버페이 공식 포인트 내역 화면에서도 함께 확인하실 수 있습니다.

Q1로그인이 되어 있는데도 "네이버 로그인이 필요합니다"라고 나옵니다.

A. 브라우저에서 nid.naver.com에 직접 접속하여 정상 로그인 상태인지 확인해 주세요. 2단계 인증이나 캡챠가 걸려 있는 경우 네이버 웹페이지에서 먼저 본인 확인을 완료하신 후 사이드 패널에서 다시 시작 버튼을 눌러주시면 됩니다.

Q2사이드 패널은 어떻게 열 수 있나요?

A. Chrome 브라우저 우측 상단 확장 프로그램 툴바에서 네줍기 (엔페이 포인트 자동 줍기) 아이콘을 클릭하시면 브라우저 우측에 사이드 패널이 바로 열립니다. 툴바에 아이콘이 보이지 않는다면 퍼즐 조각 모양 아이콘(확장 프로그램 목록)을 클릭하여 핀 고정(Pin)해 두시면 편리합니다.

Q3매일 예약 실행 기능은 브라우저를 꺼도 동작하나요?

A. 미션 실행과 예약 스케줄링이 Chrome 브라우저 내부(chrome.alarms)에서 동작하므로, Chrome 브라우저가 실행 중인 상태에서만 예약 시각에 봇이 가동됩니다. 컴퓨터가 절전 모드이거나 브라우저가 완전히 종료된 상태에서는 실행되지 않습니다.

Q4특정 미션에서 탭이 닫히지 않고 오래 머무릅니다.

A. 1원 미션, 쇼핑라이브, 체류형 추가 혜택 페이지의 경우 제휴 광고망(adcr, pincrux 등)을 거쳐 최종 페이지에 도달한 뒤 약 3~5초 이상 머물러야 적립이 확정됩니다. 쇼핑라이브 재생 탭은 자동으로 음소거 처리되며, 적립이 확인되면 탭이 자동으로 닫힙니다.

Q5예정된 쇼핑라이브 방송도 자동으로 적립할 수 있나요?

A. 네, 실행 시 방송 예정인 쇼핑라이브가 감지되면 시작 시각 10분 후 1회성 라이브 전용 적립 알람을 자동 예약합니다. 환경설정 드로어에서 해당 옵션을 켜거나 끌 수 있으며, Chrome 브라우저가 실행 중일 때 자동 수행됩니다.
